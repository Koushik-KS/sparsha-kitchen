# Sparsha Kitchen 🍽️

Sparsha Kitchen is a homemade food ordering website where customers can browse recipes, place orders, request custom recipes, and track their orders.

## 🌐 Website

Customer Website:
https://sparsha-kitchen.vercel.app

Admin Login:
https://sparsha-kitchen.vercel.app/admin/login


## Features

### Customer
- Browse homemade recipes
- View recipe details and photos
- Add food to order
- Place orders
- Request custom recipes
- Track orders using Track ID and phone number
- Confirm orders
- View payment details
- View delivery details
- Contact through WhatsApp

### Admin
- Admin login
- Manage recipes
- Manage customer orders
- Confirm customer orders
- Record payments
- Assign delivery team members
- Update order status
- Manage custom recipe requests
- Manage delivery team
- Manage business settings

### Delivery
- Delivery person assignment
- Delivery address and map location
- Delivery OTP verification
- Order delivery status tracking

##  Order Workflow

Customer Places Order  
→ Customer Confirms  
→ Admin Confirms  
→ Payment Verification  
→ Delivery Assignment  
→ Preparing  
→ Ready  
→ Out for Delivery  
→ OTP Verification  
→ Delivered

##  Payment

The system supports:

- Unpaid orders
- Partial payments
- Full payments
- Multiple payment records
- Admin payment verification
